# Libris

**Sua jornada de leitura, organizada em um só lugar.**

Libris é uma aplicação de acompanhamento de leitura desenvolvida para ajudar leitores a organizar seus livros, acompanhar seu progresso, estabelecer metas e descobrir novos hábitos de leitura.

O projeto combina desenvolvimento backend, banco de dados e integração com serviços externos, com espaço para futuras funcionalidades inteligentes.

## Funcionalidades

🚧 Projeto em desenvolvimento.

- [ ] Cadastro e autenticação de usuários
- [ ] Catálogo compartilhado de livros
- [ ] Pesquisa de livros por título, autor e ISBN
- [ ] Integração com Google Books API
- [ ] Organização da biblioteca pessoal
- [ ] Acompanhamento do progresso de leitura
- [ ] Registro de sessões de leitura
- [ ] Metas mensais e anuais
- [ ] Histórico e estatísticas de leitura
- [ ] Avaliações e resenhas
- [ ] Funcionalidades com inteligência artificial

| Tecnologia | Aplicação |

## Arquitetura planejada

O Libris será desenvolvido com uma arquitetura que separa a interface, a API e a persistência dos dados.

- **Frontend:** interface e interação com o usuário.
- **Backend:** regras de negócio e endpoints da aplicação.
- **Banco de dados:** armazenamento e relacionamento das informações.

## Objetivo do projeto

Construir uma aplicação completa, aplicando conhecimentos de programação Python, desenvolvimento de APIs, modelagem de dados, SQL e integração com serviços externos.
